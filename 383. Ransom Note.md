# 383. Ransom Note
https://leetcode.com/problems/ransom-note/submissions/

# 1st
### ロジック
①magazineの文字をカウント   
②ransomNoteの文字の数だけ上記から引き算   
③もし既に文字のカウントから0のところを引こうとしていたら、return False、回り切ればTrue   

```python
class Solution(object):
    def canConstruct(self, ransomNote, magazine):
        """
        :type ransomNote: str
        :type magazine: str
        :rtype: bool
        """
        count_char = defaultdict(int)
        for char in magazine:
            count_char[char] += 1
        for char in ransomNote:
            if count_char[char] == 0:
                return False
            count_char[char] -= 1
        return True

```

```python
class MyDefaultDict():
  def __init__(self, function):
    self.function = function
    self.original_dict = dict()

  def __setitem__(self, key, value):
    self.original_dict[key] = value
  
  def __getitem__(self, key):
    if key in self.original_dict.keys():
      return self.original_dict[key]
    else:
      return self.function()

MyDefaultDict_1 = MyDefaultDict(int)
MyDefaultDict_1[1] = 2
print(MyDefaultDict_1[1]) #2
print(MyDefaultDict_1[2]) #0
```
